ПАНЕЛЬ TUNE — ШПАРГАЛКА ПО ПАРАМЕТРАМ
=====================================

КАК ОТКРЫТЬ
  ПК:       npm run dev → http://localhost:5173/?tune=1  (в dev можно без ?tune=1 — просто нажми T)
  Телефон:  http://<IP компа>:5173/?tune=1  → кнопка TUNE слева сверху
  Клавиши:  T — панель, 1/2/3/4 — classic/smooth/rush/floaty, R — рестарт тем же seed

КНОПКИ
  classic/smooth/rush/floaty  пресет физики + рестарт (твои правки физики сбрасываются)
  A ⇄ B        два слота для сравнения: тап по пресету меняет активный слот, тап по A⇄B — переключает
  Restart      заново, тот же мир (seed)        New seed — новый мир
  Copy JSON    скопировать твои отличия от пресета (формат tuning.json)
  Save         записать tuning.json (только в npm run dev; в сборке = Copy JSON)
  Тап по названию параметра — вернуть его значение по умолчанию.
  Вкладка Hills: превью рельефа сверху, Peaks/Zigzag, Preview only, Reset Hills (см. ХОЛМЫ).
  Жёлтое название с точкой ● — параметр изменён.

ЧТО ЗНАЧАТ ЧИСЛА
  px      — пиксели мира (ширина экрана при обычном зуме = 720 px)
  px/s    — скорость; км/ч = px/s × 0.12  (1000 px/s = 120 км/ч, 3000 px/s = 360 км/ч)
  zoom    — 1.00 обычный вид; 0.50 видно в 2 раза больше; 0.36 — в 2.8 раза больше


=====================================================================
ФИЗИКА  (действует сразу, со следующего шага)
=====================================================================
Главный механизм: держишь палец — гравитация gDive, отпустил — gRelease.
Вниз с горки набираешь gDive × высота, вверх теряешь только gRelease × высота.
Разница (gDive − gRelease) = сколько скорости даёт каждый холм ("насос").

gRelease  (600–1600)  Гравитация, когда палец ОТПУЩЕН (и на земле, и в воздухе)
   ↑ больше: полёты короче и ниже, в подъём теряешь больше скорости, птица "тяжелее"
   ↓ меньше: полёты длиннее и выше, всё "лунное"
   ! Ещё влияет на ширину воды между островами (её считают по баллистике) — для
     новых островов нужен Restart.

gDive  (1800–5000)  Гравитация, когда палец ЗАЖАТ
   ↑ больше: быстрее разгон на спуске, птица резче падает по тапу в воздухе,
             сильнее "прилипает" к гребню, если держать
   ↓ меньше: разгон слабее, нажатие в воздухе почти не чувствуется

diveRamp  (0–0.15 сек)  Как быстро гравитация переключается при нажатии/отпускании
   0     = мгновенно, резко и отзывчиво
   0.05  = мягкое включение (smooth)
   ↑ больше: плавнее, но короткие тапы теряют силу, управление "вязкое"

airLift  (0–0.4)  Планирование: доля гравитации, которая гасится, пока палец отпущен
                  и птица ПАДАЕТ (крылья раскрыты)
   0     = чистая баллистика
   ↑ больше: дольше паришь на снижении, полёты длиннее, проще не упасть в воду
   ! Слишком много — птица "висит", пропадает ощущение веса

muGround  (0–0.06)  Трение о землю (сильнее всего в ложбинах, где птицу прижимает)
   ↑ больше: наказывает "держу всегда", скорость тает на земле
   ↓ меньше: птица катится почти без потерь

drag  (0–0.00008)  Сопротивление воздуха (растёт как скорость²) — "потолок" скорости
   ↑ больше: максимальная скорость ниже, разгон к концу вязнет
   ↓ меньше: можно разогнаться сильнее
   (на панели показано как 3.5e-5 = 0.000035)

greatAngle  (8–25°)  Насколько ровно надо приземлиться на спуск, чтобы был GREAT
                     (угол между полётом и склоном)
   ↑ больше: GREAT даётся легче, серии и Fever чаще
   ↓ меньше: GREAT только для точных приземлений

greatBoost  (1–1.2)  Множитель скорости за GREAT
   1.08 = +8% скорости за каждый GREAT
   ↑ больше: точность сильнее награждается, скорость растёт лавиной

landingAssist  (0–0.8)  Прощение неидеальных посадок на спуск (угол до 2 × greatAngle)
   0     = честная физика: косая посадка съедает много скорости
   ↑ больше: при кривой посадке скорость почти не теряется, игра дружелюбнее

takeoffMargin  (0–0.3)  "Липкость" гребней: насколько сильнее земля должна уходить
                        из-под птицы, чтобы она оторвалась
   0     = чистая физика
   ↑ больше: мелкие бугры не подбрасывают, взлёты реже и позже (с самого гребня)
   ! Слишком много — не взлетаешь даже с хорошего трамплина


Значения пресетов (для сравнения):
                gRelease gDive diveRamp airLift muGround drag      greatAngle greatBoost landingAssist
  classic       1000     3000  0        0       0.03     0.00004   15         1.05       0.35
  smooth        1000     3200  0.05     0.12    0.02     0.000035  17         1.08       0.45
  rush           900     3600  0.03     0       0.015    0.00003   17         1.10       0.50
  floaty         800     3000  0.08     0.25    0.02     0.000035  18         1.06       0.45
  takeoffMargin у всех = 0


=====================================================================
ХОЛМЫ  (вкладка Hills)
=====================================================================
Как устроено: рельеф — это цепочка ключевых точек ВЕРШИНА → ВПАДИНА → ВЕРШИНА…,
между ними плавная косинусная кривая (принцип Tiny Wings / haqu). Один холм =
впадина + следующая вершина. Остров = 16+ холмов, потом трамплин, вода, новый остров.
Первые 3 холма первого острова мельче и без особых впадин (обучение).

КАК ПОЛЬЗОВАТЬСЯ ВКЛАДКОЙ
  Сверху — ПРЕВЬЮ профиля для текущего seed, в настоящих пропорциях (без растяжения):
    1-я строка: остров 1, холмы 1–7 (от гнезда)   2-я: холмы 8–14   3-я: остров 4, холмы 1–7
    жёлтые точки — вершины, голубые — впадины, пунктир — уровень вершин (Peaks)
    или границы zzMinY/zzMaxY (Zigzag), белый кружок — птица для масштаба.
  Тянешь ползунок — превью меняется сразу, игра НЕ перезапускается.
  Отпустил — игра перезапускается тем же seed (если не включено Preview only).
  Под превью сводка по острову 1 и 4:
    холмов · средняя ширина холма (от вершины до вершины) · глубина впадин мин/сред/макс · самый крутой склон
  Peaks / Zigzag — генератор (см. ниже). Блоки другого режима скрываются.
  Preview only — игра не перезапускается, экспериментируй только по превью.
                 Выключишь — применится одним рестартом. (Пока включено, новые куски
                 трассы впереди в текущем забеге уже строятся по новым числам.)
  Reset Hills  — вернуть все холмы и рост островов к значениям по умолчанию (физику не трогает).
  New seed     — другой мир: проверь, что настройка хороша не только на одном seed.

РЕЖИМЫ
  Peaks  (по умолчанию, как в Tiny Wings): вершины примерно на одной высоте и через
         равные промежутки, меняется ГЛУБИНА каждой впадины, иногда впадина ШИРЕ.
         Ритм предсказуемый — можно учиться попадать.
  Zigzag (оригинал haqu): каждая точка = предыдущая ± случайный шаг, вершины гуляют
         вверх-вниз. Хаотичнее, сложнее читать, но разнообразнее.

--- Ритм (оба режима) ---
halfW  (200–800 px)  Расстояние вершина → впадина (целый холм = 2 × halfW)
   ↑ шире: склоны положе, больше времени на реакцию, полёты длиннее, ритм медленнее
   ↓ уже:  холмы частые и крутые, ритм быстрый, нажимать надо чаще и точнее
halfWJitter  (0–0.3)  Разброс ширины (0.08 = ±8%)
   0 = метроном, идеально предсказуемо; ↑ = ритм "сбивается", сложнее
symmetric  вкл/выкл  Оба склона одной впадины одинаковой ширины (ровная чаша)
   выкл: спуск и подъём разной ширины — посадка и взлёт ощущаются по-разному

--- Вершины (Peaks) ---
peakY  (0–400)  Высота уровня вершин (гнездо стоит на 200)
   Почти не влияет на ощущение — сдвигает весь рельеф вверх/вниз. Обычно не трогать.
peakJitter  (0–80 px)  Разброс высоты вершин
   0 = все гребни на одной линии, взлёты одинаковые и предсказуемые
   ↑ = взлёты непредсказуемые: то трамплин, то "недолёт"

--- Впадины (Peaks) ---
depth  (60–400 px)  Глубина впадины под вершинами — ГЛАВНЫЙ параметр рельефа
   ↑ глубже: больше скорости за каждый холм, выше взлёты, холмы лучше видно
             издалека; но круче склоны и жёстче кривые посадки
   ↓ мельче: спокойнее, медленнее, "рябь" при отдалённой камере
depthJitter  (0–0.5)  Разброс глубины (0.15 = ±15%)
   ↑ = каждая впадина своя, меньше однообразия, но ритм менее ровный
deepChance  (0–0.6)  Доля ГЛУБОКИХ впадин (0.2 = каждая пятая)
deepMul  (1–2.2)  Во сколько раз глубокая впадина глубже обычной
   Глубокая впадина = большой "насос" скорости и высокий взлёт, награда за точность.
   Слишком часто/глубоко — круто, легко потерять скорость на кривой посадке.
wideChance  (0–0.6)  Доля ШИРОКИХ впадин
wideMul  (1–2)  Во сколько раз широкая впадина шире
   Широкая впадина = длинный пологий разгон, длинный полёт, передышка в ритме.
noRepeat  вкл/выкл  После глубокой/широкой впадины следующая — всегда обычная
   вкл = особые впадины не идут подряд, ритм читается лучше

--- Рост (оба режима) ---
growFrom / growTo  (0.5–1.5)  Множитель глубины первой / последней впадины острова
   По умолчанию 0.85 → 1.12: к концу острова холмы глубже (разгон перед трамплином).
   Одинаковые значения = глубина не меняется по острову.
isl.sxStep / isl.sxMax  Рост ШИРИНЫ от острова к острову
   масштаб острова k = min(1 + sxStep × (k−1), sxMax). По умолчанию 0.05 / 1.4
isl.syStep / isl.syMax  Рост ГЛУБИНЫ от острова к острову (так же)
   По умолчанию 0.07 / 1.5. На скорости камера отдаляется и холмы выглядят мельче —
   если на поздних островах "рябь", подними: syStep 0.12, syMax 1.9.
maxSlope  (0.5–1.6)  Максимальная крутизна склона (1.1 ≈ 48°)
   Если впадина глубокая, а склон узкий — склон сам расширяется до этой крутизны.
   ↓ = всё положе и мягче; ↑ = разрешены крутые стенки (жёсткие посадки)

--- Zigzag (только режим Zigzag) ---
zzMinDY / zzRangeDY  Шаг вниз/вверх между точками = zzMinDY + случайно до zzRangeDY
   ↑ zzMinDY: холмы в среднем выше; ↑ zzRangeDY: сильнее разброс, хаотичнее
zzMinY / zzMaxY  Нижняя и верхняя граница, за которую точки не выходят
   Узкий коридор = рельеф ровнее; широкий = большие перепады


=====================================================================
КАМЕРА  (вкладка Camera; действует сразу)
=====================================================================
Камера отдаляется со скоростью (чтобы видеть путь впереди) и с высотой
(чтобы птица не вылетала из кадра). Все движения — плавные "пружины".
Значения w — жёсткость пружины: больше = быстрее и резче, меньше = мягче и с запаздыванием.

wX  (0–12)  Насколько жёстко камера держит птицу по горизонтали
   0     = птица прибита к одному месту экрана
   ↓ меньше: при разгоне/торможении птица заметно гуляет по экрану
   ↑ больше: птица почти неподвижна на экране

wY  (0.5–12)  Скорость слежения по вертикали
   ↑ больше: камера быстро догоняет, но резче на посадках
   ↓ меньше: плавнее, но земля может "уплывать" вниз/вверх

wZoomOut  (0.5–12)  Как быстро камера ОТДАЛЯЕТСЯ (разгон, высокий полёт)
   ↓ меньше: птица может подойти близко к краю кадра при резком взлёте

wZoomIn  (0.3–8)  Как быстро камера ПРИБЛИЖАЕТСЯ обратно
   ↓ меньше: спокойнее, без "дыхания" зума
   ↑ больше: картинка часто пульсирует

lookAhead  (0.3–1.2 сек)  Сколько секунд пути впереди видно на скорости
   ↑ больше: на скорости камера отдаляется сильнее — видно дальше, но холмы мельче
   ↓ меньше: крупнее, но меньше времени увидеть следующий холм

zMin  (0.2–0.8)  Максимальное отдаление ОТ СКОРОСТИ (1 = не отдаляться вообще)
   0.36 = вид в 2.8 раза шире обычного
   ↑ больше: на скорости всё крупнее, но хуже видно впереди
   ! При высоких полётах камера всё равно отдаляется сильнее (по высоте)

По умолчанию: wX 5, wY 5, wZoomOut 5, wZoomIn 2.5, lookAhead 0.7, zMin 0.36


=====================================================================
ЕСЛИ ОЩУЩАЕТСЯ ТАК — КРУТИ ЭТО
=====================================================================
  Медленно разгоняется               gDive ↑, muGround ↓, depth ↑
  Слишком быстро становится скучно   drag ↑, greatBoost ↓
  Полёты короткие, "кирпич"          gRelease ↓, airLift ↑
  Летает как на Луне                 gRelease ↑, airLift ↓
  Тап в воздухе не чувствуется       gDive ↑, diveRamp ↓
  Управление резкое, дёрганое        diveRamp ↑ (0.05–0.08)
  Подбрасывает на мелких буграх      takeoffMargin ↑ (0.05–0.1)
  Не получается GREAT                greatAngle ↑, landingAssist ↑
  GREAT слишком легко                greatAngle ↓
  Кривая посадка убивает скорость    landingAssist ↑
  Холмы непредсказуемые              peakJitter ↓, halfWJitter ↓, deepChance/wideChance ↓
  Однообразно                        depthJitter ↑, deepChance ↑, wideChance ↑
  Мало скорости с холмов             depth ↑ (или deepChance ↑)
  Жёсткие посадки, крутые стенки     maxSlope ↓, halfW ↑, deepMul ↓
  На поздних островах рябь           isl.syStep ↑, isl.syMax ↑ (или lookAhead ↓)
  Камера "дышит" зумом               wZoomIn ↓, wZoomOut ↓
  Птица уезжает по экрану            wX ↑
  Камера дёргается на посадках       wY ↓

СОВЕТ: меняй 1–2 параметра за раз, сравнивай через A⇄B на одном seed,
понравилось — Save (или Copy JSON → вставить в tuning.json).
